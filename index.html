Privacy Policy

Effective date: October 6, 2026

Developer: PureCore

Signal is a network diagnostics application designed to analyze Wi-Fi, mobile network and internet connection quality. Signal does not require a user account and does not contain advertising or behavioral analytics.

1. Information processed on the device

Signal may process technical network information provided by Android, including Wi-Fi signal strength, SSID, BSSID, frequency, channel, channel width, Wi-Fi standard, nearby Wi-Fi networks, mobile network type, mobile signal values such as RSRP, RSRQ, RSSI and SINR, SIM/subscription information required for selecting the active mobile connection, and related technical connection information.

This information is used to provide Signal's network analysis features. Wi-Fi channel analysis, repeater placement measurements, signal statistics and related calculations are performed locally on the device.

Signal does not create a location history or user profile from this information.

2. Location permission and Wi-Fi scanning

Android may require location permission and enabled location services to provide certain Wi-Fi information and Wi-Fi scan results, including information about the connected Wi-Fi network and nearby networks.

Signal uses this permission for Wi-Fi analysis. Signal does not request or record GPS coordinates for these functions and does not use the permission to track the user's physical location.

3. Phone and mobile network information

Signal may request phone-state permission to access technical information about active mobile subscriptions and SIM slots and to obtain mobile network signal information.

Signal does not use this permission to access phone calls, SMS messages or contacts.

4. Internet and network diagnostics

Some Signal functions actively communicate with internet services in order to measure connection availability, latency and bandwidth.

These diagnostic connections may use infrastructure operated by Cloudflare and Google, including Cloudflare speed-test and connectivity services, Cloudflare's 1.1.1.1 service, and Google connectivity services or 8.8.8.8.

When an internet connection is made, the destination service can necessarily receive technical network information such as the public IP address and other standard connection metadata.

Signal does not use these requests to create advertising profiles or track users across apps or websites. Processing performed independently by external service providers is subject to their respective privacy policies.

5. Speed tests and mobile data

Speed tests transfer test data over the internet to measure download and upload performance.

When a speed test is performed over a mobile network, Signal provides controls governing whether the bandwidth test may use mobile data. Depending on connection performance, a speed test may transfer a significant amount of data.

6. Local measurements and storage

Signal processes measurements required for its diagnostic functions locally on the device. Temporary measurement samples may be retained in memory while a measurement is running.

Signal does not operate a developer-controlled server for collecting network measurement histories and does not create a cloud-based history of the user's Wi-Fi or mobile signal measurements.

Application preferences may be stored locally on the device using Android's application storage mechanisms.

7. Advertising, analytics and user accounts

Signal does not require a user account. Signal does not contain advertising and does not use analyzed network information for behavioral advertising.

The current version of Signal does not use a third-party analytics system to build usage profiles of users.

8. Sale of data

PureCore does not sell Signal users' personal data.

9. Security and data minimization

Signal is designed to minimize unnecessary collection and transmission of information. Network information used for local diagnostic functions remains on the device unless transmission is technically required for an explicitly network-based diagnostic function.

10. Changes to this Privacy Policy

This Privacy Policy may be updated when Signal's functionality, permissions or data-processing practices change. The current version will be made available through the application's Google Play listing and/or within the application.

11. Contact

For privacy-related questions concerning Signal:

Datenschutzerklärung

Stand: 6. Oktober 2026

Entwickler: PureCore

Signal ist eine Anwendung zur technischen Analyse von WLAN-, Mobilfunk- und Internetverbindungen. Signal benötigt kein Benutzerkonto und enthält keine Werbung oder verhaltensbasierte Analysefunktionen.

1. Auf dem Gerät verarbeitete Informationen

Signal kann von Android bereitgestellte technische Netzwerkdaten verarbeiten. Dazu gehören unter anderem WLAN-Signalstärke, SSID, BSSID, Frequenz, Kanal, Kanalbreite, WLAN-Standard, Informationen über WLAN-Netzwerke in der Umgebung, Mobilfunkstandard, Mobilfunksignalwerte wie RSRP, RSRQ, RSSI und SINR sowie für die Auswahl der Mobilfunkverbindung erforderliche SIM-/Abonnementinformationen und zugehörige technische Verbindungsinformationen.

Diese Informationen werden verwendet, um die Netzwerkdiagnosefunktionen von Signal bereitzustellen. WLAN-Kanalanalyse, Repeater-Positionsmessung, Signalstatistiken und die zugehörigen Berechnungen erfolgen lokal auf dem Gerät.

Signal erstellt daraus weder einen Standortverlauf noch ein Benutzerprofil.

2. Standortberechtigung und WLAN-Scans

Android kann für den Zugriff auf bestimmte WLAN-Informationen und WLAN-Scanergebnisse eine Standortberechtigung sowie aktivierte Standortdienste voraussetzen.

Signal verwendet diese Berechtigung für die WLAN-Analyse. Signal fragt für diese Funktionen keine GPS-Koordinaten ab, zeichnet keine GPS-Koordinaten auf und verwendet die Berechtigung nicht zur Verfolgung des physischen Standorts des Nutzers.

3. Telefon- und Mobilfunkinformationen

Signal kann die Telefonstatus-Berechtigung benötigen, um technische Informationen über aktive Mobilfunkabonnements beziehungsweise SIM-Steckplätze sowie Mobilfunksignalwerte auszulesen.

Signal verwendet diese Berechtigung nicht zum Zugriff auf Telefonate, SMS-Nachrichten oder Kontakte.

4. Internet- und Netzwerkdiagnose

Einige Funktionen von Signal stellen aktiv Internetverbindungen her, um Erreichbarkeit, Latenz und Bandbreite zu messen.

Hierfür können Dienste beziehungsweise Infrastruktur von Cloudflare und Google verwendet werden, darunter Cloudflare-Speedtest- und Connectivity-Dienste, Cloudflares Dienst 1.1.1.1 sowie Google-Connectivity-Dienste beziehungsweise 8.8.8.8.

Bei einer Internetverbindung erhält der jeweilige Zielserver technisch notwendigerweise bestimmte Verbindungsinformationen, insbesondere die öffentliche IP-Adresse und übliche Netzwerk-Metadaten.

Signal verwendet diese Verbindungen nicht, um Werbeprofile zu erstellen oder Nutzer über andere Apps oder Websites hinweg zu verfolgen. Für die eigenständige Verarbeitung durch diese externen Anbieter gelten deren jeweilige Datenschutzbestimmungen.

5. Geschwindigkeitstests und mobile Daten

Bei Geschwindigkeitstests werden Testdaten über das Internet übertragen, um die Download- und Upload-Leistung der Verbindung zu messen.

Bei Verwendung einer Mobilfunkverbindung bietet Signal Einstellungen beziehungsweise eine Abfrage dafür, ob der Bandbreitentest mobile Daten verwenden darf. Abhängig von der Geschwindigkeit der Verbindung kann ein Geschwindigkeitstest eine erhebliche Datenmenge übertragen.

6. Lokale Messungen und Speicherung

Signal verarbeitet die für seine Diagnosefunktionen benötigten Messwerte lokal auf dem Gerät. Während einer laufenden Messung können Messwerte vorübergehend im Arbeitsspeicher gehalten werden.

Signal betreibt keinen eigenen Entwickler-Server zur Sammlung einer Historie der Netzwerkmessungen und erstellt keine cloudbasierte Historie der WLAN- oder Mobilfunksignalmessungen des Nutzers.

App-Einstellungen können über die lokalen Speichermechanismen von Android auf dem Gerät gespeichert werden.

7. Werbung, Analyse und Benutzerkonten

Signal benötigt kein Benutzerkonto. Signal enthält keine Werbung und verwendet die analysierten Netzwerkdaten nicht für verhaltensbasierte Werbung.

In der aktuellen Version von Signal wird kein Analysedienst eines Drittanbieters eingesetzt, um Nutzungsprofile der Nutzer zu erstellen.

8. Verkauf von Daten

PureCore verkauft keine personenbezogenen Daten der Nutzer von Signal.

9. Sicherheit und Datenminimierung

Signal ist darauf ausgelegt, unnötige Erhebung und Übertragung von Informationen zu vermeiden. Netzwerkdaten, die für lokale Diagnosefunktionen verwendet werden, verbleiben auf dem Gerät, sofern ihre Übertragung nicht technisch für eine ausdrücklich netzwerkbasierte Diagnosefunktion erforderlich ist.

10. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann aktualisiert werden, wenn sich Funktionen, Berechtigungen oder die Datenverarbeitung von Signal ändern. Die jeweils aktuelle Version wird über den Google-Play-Eintrag der Anwendung und/oder innerhalb der Anwendung zugänglich gemacht.
